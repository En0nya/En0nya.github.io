浮点数比较

浮点数表示的原理暂且不提。

判断是否就是给定一个 ϵ\epsilonϵ，然后比较两浮点数之差的绝对值是否小于这个 ϵ\epsilonϵ，如果是那么认为两数取等。

一般来说 ϵ\epsilonϵ 比精度要求多取两位。

如果不相等就可以直接大小比较。

double eps = numeric_limits<double>::epsilon(); // in <limits>
bool feq(double a, double b) {
	return fabs(a - b) < eps ? 1 : 0;
}

向量叉积

若 A=(x1,y1),B=(x2,y2)\textbf{A} = (x_1, y_1), \textbf{B} = (x_2, y_2)A=(x1​,y1​),B=(x2​,y2​)，A, B\textbf{A, B}A, B 的叉积为一个向量 C\textbf{C}C。

其中 ∣C∣=x1y2−x2y1|\textbf{C}| = x_1y_2 - x_2y_1∣C∣=x1​y2​−x2​y1​，且 (A, B, C)(\textbf{A, B, C})(A, B, C) 构成右手系（右手食指为 A\textbf{A}A，中指为 B\textbf{B}B，大拇指为 C\textbf{C}C）

  • 一个特性：叉积是有顺序的，A×B=−(B×A)\textbf{A} \times \textbf{B} = -(\textbf{B} \times \textbf{A})A×B=−(B×A)。
  • 叉积还可以判断两个向量的位置关系：
    • 如果 A×B>0\textbf{A} \times \textbf{B} > 0A×B>0，那么由 A\textbf{A}A 逆时针旋转到 B\textbf{B}B 的方向只需要转一个优角。
    • 如果 A×B<0\textbf{A} \times \textbf{B} < 0A×B<0，那么需要转过一个劣角
    • 如果 A×B=0\textbf{A} \times \textbf{B} = 0A×B=0，那么两向量一定共线但是方向不能确定是否相同。

怎么理解？以 A\textbf{A}A 为坐标原点，观察 B\textbf{B}B 的落点就能看出来了。

点是否在线段上

已知两个端点 P,QP, QP,Q，有一点 AAA。

可以先判断 AP⃗,AQ⃗\vec{AP}, \vec{AQ}AP,AQ​ 是否共线，如果不共线那么 AAA 必定不在 P,QP, QP,Q 上

如果共线，还可能在线段外，此时判断一下 AP⃗,AQ⃗\vec{AP}, \vec{AQ}AP,AQ​ 是否异向就可以。

点是否在三角形上（内）

如果多边形只是三角形的话方法会简单一些。

任意取出两个顶点计算其和点构成的三角形面积，三个三角形面积之和若等于三角形就说明点在三角形内（上）。

由于在二维平面上，叉积的意义表示两向量构成平行四边形的面积，所以也可以用来计算三角形的面积即：

SΔAPQ=12×∣AP⃗×AQ⃗∣S_{\Delta APQ} = \dfrac{1}{2}\times |\vec{AP} \times \vec{AQ}|SΔAPQ​=21​×∣AP×AQ​∣

要判断是否在边上只需要套用上面的方法。

线段相交

由于接下来的很多问题都需要判断是否相交所以先在这里提及。

在算法竞赛的计算几何里，由于浮点数的误差存在，所以一般不会考虑使用类似平面解析几何那样的计算法。

不妨先粗略的判定两条线段 AB,CDAB,CDAB,CD 是否有相交的可能，“隔得太远”显然是不可能相交的。

我们分别以这两条线段为对角线构建两个矩形，如果没有重合区域那么显然是不相交的，此为 快速排斥实验

只需要判断由 CDCDCD 生成的矩形是否存在一个顶点在 ABABAB 生成的矩形内部（上）即可。

当然通过了快速排斥实验不代表它们一定相交，万一没有相互穿过只是差不多贴近了呢？

此时可以直接判断 C,DC,DC,D 两点是否在线段 ABABAB 的两边，这个利用叉积很容易做到，此为 跨立实验

一个想法是直接做垂线 AD,BEAD, BEAD,BE，然后可以知道 ΔAPD∼ΔBPE\Delta APD \sim \Delta BPEΔAPD∼ΔBPE。

点是否在多边形内（PIP 问题）

以下默认为平面多边形，在多边形上不加说明考虑进入在多边形内的情况。

  • 简单多边形：没有边自交的多边形

左边两个就是简单多边形，右边两个一般在 PIP 中不考虑，因为这类多边形的内部定义需要单独讨论。

Ray casting

对于简单多边形，有一个 Jordan curve 定理告诉我们，当我们从一点发出一条射线与多边形相交时，每相交一次就改变一次内外关系。

所以我们只需要判断相交次数的奇偶性就可以了，不过还有一些细节：

首先就是射线，由于我们用射线判断相交并不是那么方便，我们可以取一个数据范围之外的点 FFF，取线段 PFPFPF 来进行判断

理所应当的，还需要判断点是否在多边形的边上，这里就是 O(n)O(n)O(n) 的复杂度瓶颈了。
