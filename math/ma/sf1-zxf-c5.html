定义 5.1 不定积分

若在某个区间 III 上，函数 f,Ff, Ff,F 满足以下关系：

F′(x)=f(x),x∈IF^{\prime}(x) = f(x), x\in IF′(x)=f(x),x∈I。

或者等价地： dF(x)=f(x)dx\text{d} F(x) = f(x) \text{d} xdF(x)=f(x)dx。

则称 FFF 为 fff 在 III 上的一个原函数。

函数 fff 的全体原函数称为 fff 的不定积分

记作 ∫f(x)dx\displaystyle\int f(x)\text{d}x∫f(x)dx，由此：F(x)=∫f(x)dx+CF(x) = \displaystyle\int f(x) \text{d}x + CF(x)=∫f(x)dx+C，其中 CCC 为任意常数。

例：∫xdx=12x2+C\displaystyle\int x \text{d} x = \dfrac{1}{2}x^2 + C∫xdx=21​x2+C

原函数求导得到导函数

导函数求不定积分得到原函数

所以求导和不定积分一定程度上是逆运算（由于 CCC 所以不完全是）

命题 5.1

若 f(x),g(x)f(x), g(x)f(x),g(x) 的原函数都存在，则 ∀α,β∈R;  αf(x)+βg(x)\forall \alpha,\beta \in \mathbb R; \; \alpha f(x) + \beta g(x)∀α,β∈R;αf(x)+βg(x) 的原函数也存在。

且满足：∫[αf(x)+βg(x)]dx=α∫f(x)dx+β∫g(x)dx\displaystyle\int [\alpha f(x) + \beta g(x)] \text{d} x= \alpha \displaystyle\int f(x)\text{d}x + \beta \displaystyle\int g(x)\text{d}x∫[αf(x)+βg(x)]dx=α∫f(x)dx+β∫g(x)dx

所以 [αF(x)+βG(x)]′=αf(x)+βg(x)[\alpha F(x) + \beta G(x)]^{\prime} = \alpha f(x) + \beta g(x)[αF(x)+βG(x)]′=αf(x)+βg(x)

那么 αF(x)+βG(x)\alpha F(x) + \beta G(x)αF(x)+βG(x) 是 αf(x)+βg(x)\alpha f(x) + \beta g(x)αf(x)+βg(x) 的一个原函数

也就是 ∫[αf(x)+βg(x)]dx+C=αF(x)+βG(x)\displaystyle\int[\alpha f(x) + \beta g(x)]\text{d}x + C = \alpha F(x) + \beta G(x)∫[αf(x)+βg(x)]dx+C=αF(x)+βG(x)

所以 ∫[αf(x)+βg(x)]dx+C=α∫f(x)dx+αC1+β∫g(x)dx+βC2\displaystyle\int[\alpha f(x) + \beta g(x)]\text{d}x + C = \alpha \displaystyle\int f(x)\text{d}x + \alpha C_1 + \beta \displaystyle\int g(x)\text{d}x + \beta C_2∫[αf(x)+βg(x)]dx+C=α∫f(x)dx+αC1​+β∫g(x)dx+βC2​

=α∫f(x)dx+β∫g(x)dx= \alpha \displaystyle\int f(x)\text{d}x + \beta \displaystyle\int g(x)\text{d}x=α∫f(x)dx+β∫g(x)dx

这里不是在消掉 CCC 而是因为本身就带常数给扔到里面去了。

有理函数裂项

有理函数形如一个多项式除以一个多项式。

例子

∫4x3−13x2+3x+8(x+1)(x−2)(x−1)2dx=\displaystyle\int \dfrac{4x^3 - 13x^2 + 3x + 8}{(x + 1)(x - 2)(x - 1)^2}\text{d}x =∫(x+1)(x−2)(x−1)24x3−13x2+3x+8​dx=？

设 4x3−13x2+3x+8(x+1)(x−2)(x−1)2=ax+1+bx−2+cx+d(x−1)2\dfrac{4x^3 - 13x^2 + 3x + 8}{(x + 1)(x - 2)(x - 1)^2} = \dfrac{a}{x + 1} + \dfrac{b}{x - 2} + \dfrac{cx + d}{(x - 1)^2}(x+1)(x−2)(x−1)24x3−13x2+3x+8​=x+1a​+x−2b​+(x−1)2cx+d​

待定的分子设成什么样完全根据多项式的阶数差决定。

4x3−13x2+3x+8=a(x−2)(x−1)2+b(x+1)(x−1)2+(cx+d)(x+1)(x−2)4x^3 - 13x^2 + 3x + 8 = a(x - 2)(x - 1)^2 + b(x + 1)(x - 1)^2 + (cx + d)(x + 1)(x - 2)4x3−13x2+3x+8=a(x−2)(x−1)2+b(x+1)(x−1)2+(cx+d)(x+1)(x−2)

这样子写不需要考虑分母为 000 的问题，甚至可以把这些 xxx 带进去快速得到结果。

x=1,x=2,x=−1x = 1, x = 2, x = -1x=1,x=2,x=−1 全部带入：

可以得到：

{a=1b=−2c+d=−1\begin{cases}a = 1\\ b = -2\\ c + d = -1\end{cases}⎩⎨⎧​a=1b=−2c+d=−1​

再取 x=0x = 0x=0 可以知道 c=5,d=−6c = 5,d = -6c=5,d=−6
